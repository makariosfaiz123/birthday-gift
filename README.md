# 🎂 Birthday Gift Website

موقع هدية عيد ميلاد مصمّم للموبايل أولًا (mobile-first): شاشة قفل بكود سري، رسالة بتتكتب حرف حرف، ألبوم صور وفيديوهات، سؤال، كروت ذكريات، وشمعة بالنهاية. HTML و CSS و JavaScript عادي، من غير build ولا سيرفر.


وافتح `http://localhost:5173` (يُفضّل بمقاس موبايل من أدوات المتصفح). محتاج نت عشان الخطوط (Google Fonts).

## تعديل المحتوى

كل النصوص والصور في ملف واحد: [`js/content.js`](js/content.js).

- **الكود السري:** `lockCode` (عدد النقط بيتظبط على طول الكود).
- **الرسالة:** `letter.body`. `\n\n` معناها فقرة جديدة.
- **الألبوم:** `album.items`. كل عنصر صورة أو فيديو، والنوع بيتعرف من الامتداد:

  ```js
  { src: "assets/album/01.jpg", text: "الكلام اللي بيظهر تحت الصورة" },
  { src: "assets/album/02.mp4", text: "فيديو", poster: "assets/album/02.jpg" },
  ```

- **الكروت:** `moments.cards` — `src` و `date` و `text` (لحد 3 سطور).
- **السؤال:** `question.photo` و `question.donePhoto` (بعد Yes).
- **الشمعة والرسالة الأخيرة:** `candle`.

أي `src` فاضي أو ملف مش موجود بيظهر مربع تجريبي بدل ما الموقع يقع.

### الصور والفيديو والمقاسات

- **الألبوم:** الكارت بيتفصّل على شكل كل صورة (طولية/عرضية/بانوراما) من غير قص، والصورة بتتصغّر لحد ما تدخل في المساحة المتاحة. الأسهم والأزرار مابتتحركش.
- **الكروت:** الكارت ثابت، فالصورة بتظهر كاملة وحواليها نسخة مغبّشة منها.
- **الفيديو:** بيشتغل من غير صوت، لمسة بتوقفه، وفيه زرار صوت. لما الصوت يتفتح الأغنية بتقف لحد ما يتقفل أو تنتقل لصورة تانية.
- **نصايح للسرعة على الموبايل:** JPG/PNG/WebP/GIF للصور (صور الآيفون HEIC حوّلها JPG)، و MP4 (H.264) للفيديو. الصورة أقل من ~1MB والفيديو أقل من ~15MB.

## النشر

موقع static بالكامل، فأي استضافة ملفات تنفع (Vercel أو Netlify أو Cloudflare Pages): اربط الـ repo، من غير build command، والـ output directory هو الفولدر الرئيسي.

⚠️ **خلّي بالك:**
- فحص الكود السري بيحصل في المتصفح، يعني الكود ظاهر لأي حد يفتح الـ source. هو بوابة للهدية مش حماية حقيقية.
- لو الـ repo عام، النصوص والصور والكود هيبقوا ظاهرين لأي حد. الأفضل يبقى **Private**.
- ملف الأغنية حقوقه لأصحابها. لو هتنشر الـ repo علنًا استبدله بأغنية تملك حقها.
